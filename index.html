L'Apprenti Alchimiste

Livre de Recette

Guide

Jeune apprenti alchimiste, mais tu es face à un "petit" problème.
À la suite d'un accident avec une potion, ton manuel contenant toutes les recettes a disparu.
À toi d'essayer d'en écrire un nouveau en expérimentant avec les ingrédients à ta disposition.

Sur Desktop

Prends un des ingrédients et dépose-le dans le chaudron.
Si tu ne veux plus d'un ingrédient, tu peux le remettre avec les autres.

Il est également possible de cliquer directement sur un ingrédient pour le mettre dans le chaudron.
Clique sur un ingrédient dans le chaudron pour le remettre avec les autres.

Sur Mobile

Clique sur un ingrédient pour le mettre dans le chaudron.
Clique sur un ingrédient dans le chaudron pour le remettre avec les autres.
